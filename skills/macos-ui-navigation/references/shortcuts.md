# Reliable macOS shortcuts

| Where | Action | Keys |
|---|---|---|
| Any app | New window / document | `cmd+n` |
| Any app | Find in window | `cmd+f` |
| Any app | Close window | `cmd+w` (asks first) |
| Any app | Settings | `cmd+,` |
| Browser | Focus the address bar | `cmd+l` |
| Browser | New tab | `cmd+t` |
| Browser | Reload | `cmd+r` |
| Finder | Go to folder | `cmd+shift+g` |
| Finder | New folder | `cmd+shift+n` |
| Notes | New note | `cmd+n` |
| Music | Play / pause | `space` |
| Text fields | Select all | `cmd+a` |
